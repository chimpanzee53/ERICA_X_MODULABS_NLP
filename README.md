# NLP Learning Repository

한양대학교 ERICA 자연어처리(NLP) 교육과정에서 진행하는 실습 및 프로젝트 결과물을 관리하기 위한 Repository입니다.

## 프로젝트 소개

자연어처리의 주요 개념과 기술을 학습하고, 실습을 통해 텍스트 데이터 분석 및 AI 모델 활용 능력을 익히는 것을 목표로 합니다.

## 학습 내용

- 텍스트 데이터 전처리 및 분석
- 영화 리뷰 텍스트 감성 분석
- 뉴스 요약 모델 구현
- 트랜스포머 기반 대화형 챗봇
- 자연어처리 프로젝트 수행

## 프로젝트 관리

각 실습 폴더에는 실습 코드와 결과물, `README.md`를 저장합니다.

`README.md`에는 Peer Review Template(PRT)을 기반으로 코드 리뷰, 문제 해결 과정, 추가 실험 및 회고를 기록합니다.
